# 从这里开始：上传资料后怎么做

**建议先提供选型软件导出的原生 Excel（.xlsx）。Excel 和 PDF 不必同时上传。** 原生 Excel 便于逐台核对，可能包含规格书打印页未展示的字段，例如开启、关闭需求推力；但是否够用取决于实际内容和版本，不能只凭文件格式判断。只有 PDF 也可以开始，不要求先转成 Excel。

## 先准备什么

| 资料 | 什么时候需要 |
| --- | --- |
| 原选型 Excel | 优先提供软件直接导出的完整文件，保留工作表、列名、单位及位号。手工汇总表或 PDF 转出的 Excel 不自动视为完整原生数据。 |
| 原选型 PDF | Excel 缺少工况、说明、配置、原计算结果或推力含义时，补相应页面；只有 PDF 时直接读。可选文字的 PDF 优先，扫描件需核对数字、单位和表格列。不要为了凑格式重复提交全部资料。 |
| 客户数据表、技术协议或已确认要求 | 核对管径、设计条件、关闭压差、最低保证气源、噪声及泄漏等要求。选型书描述原方案，不自动代表客户已经接受；约束未明确时可先做有条件分析。 |
| 厂家样本、曲线、推力明细或价格 | 开始时不要求一次交齐。先用已有资料；具体判断缺依据时，再说明需要哪一项、会影响什么。没有可比价格不报精确节省金额。 |

如果 Excel 已包含本轮所需工况、配置、原结果和可追溯的需求推力，就不为相同信息重复索取 PDF。若两份资料版本不同或数值冲突，按位号保留两边原值，核对采用哪版；不能因为是 Excel 就覆盖更晚或经确认的 PDF。已有开启/关闭需求推力可用于有条件执行机构比较，字段包含项不明时只补相应说明，不把缺少全行程负荷变成整批停止。

## 开始时先核对执行机构安全系数

安全系数是执行机构相对所需开启/关闭力或力矩必须保留的设计余量；有了需求值，还要取得本轮适用的系数，才能判断执行机构是否足够。在首次资料核对阶段查当前要求、原选型 Excel 的 `Safety Factor`、PDF 及本任务已确认信息，按位号和版本记录来源；同时区分原方案采用值和客户要求值。供气余量、压差加成、Cv容量余量不能代替执行机构安全系数。

- **资料已有且适用、没有冲突：** 主动说明“资料中的执行机构安全系数为××，来自××，适用于××位号；本轮按此比较。”然后继续，不重复要求用户确认。批次内数值不同时分组说明，不能把一台的值套给全批。
- **查过资料仍缺失：** 在开始阶段询问：“本轮执行机构选型要求的安全系数是多少？如果不同位号或开启、关闭方向要求不同，请分别说明。”不要默认取1、沿用其他项目或把软件默认值当用户要求；本任务已明确回答过的值直接沿用。
- **来源冲突或适用范围不明：** 先按最新明确客户要求或本任务澄清处理；仍无法确定时列出相冲突的数值、来源及受影响位号，集中询问采用哪一个。等待答复时继续容量、开度、喉径和行程等独立工作；受影响执行机构保留“安全系数待明确”，不能宣布够用或选用更小执行机构。

取得系数后，按[需求字段包含关系核对](actuator-force-followup.md#11-如何判定需求是否已含安全系数)查明是否已计入：已含不重复乘，未含按有据方法增加。系数栏、近似倍数或改系数后数值没变都不能单独作证。已有原执行机构配置时，先按原供气、实际行程和弹簧范围反查开关能力，并比较较小档位；按有区分力样本的主导结果确定同批已含/未含的初算口径，异常单列，然后继续优化。正式三表只展示采用的一套门槛，并标明直接依据或批次推定；仍不足以判断时才标具体缺项，不让用户在两套分支中自行选择。

## 上传后说这一句

> 请按这份阀门优化指南开始，全程用中文，正式结果只给总览和逐台优化清单，原始数据另存备查。先用三步简要说明流程，再检查我已上传的资料；有数据就继续，不要逐步等待我确认。先判断每台有哪些值得尝试的优化方向，输出完整清单，预计开度和执行机构一起列出。确实缺什么，再集中告诉我具体缺项及影响。

可以补充“先看哪套装置、哪些位号、哪些配置不能改”。没有特别限定时，先按提供资料的全部有效位号核对范围；多装置/多版本关系不明时先分列，询问会改变范围的歧义，不把同一阀门不同版本重复计数。不要继承其他项目的台数、气源值或临时豁免。

## 流程只有三步

1. **核对资料，固定原方案。** 对应位号、数量和版本，整理全部源工况、原阀门、CV、机械行程、执行机构及客户要求，并按上文先查明安全系数；已有则告知后继续，缺失才询问。先给“已识别多少个位号、多少台、哪些资料可用、哪些缺项影响判断”的简短回执；同一台的多工况不是多台阀门。可复用的同版本数据不重新提取。
2. **逐台判断，先在软件外比较。** 按 11 种通用方法和 38 条具体案例检查全部阀门。有数据与适用依据时算容量、预计开度、流速或执行机构力/供气；同时比较缩阀体、同口径减 Cv、较小执行机构及适用配置替换。工具或数据不足就标注条件，继续其他有依据的方向，不用虚构数值填满表格。
3. **给出完整清单，再挑值得复核的方案。** 最前面展示有优化机会的阀门及关键代价，每台保留最有依据的少量候选；其余阀门和不继续的理由留在本地备查记录。使用者据此决定哪些候选送软件或厂家复核；初筛不以已经进入软件为完成条件。

## 正式输出规范：中文、简洁、逐台说清

输出按[固定三表格式](excel-format.md)，该文件是展示格式的唯一维护依据。完整Excel指完整的优化报告，不是把全部原始字段、无变化的计算或备查附录塞进报告。

输出前读取上述格式文件，使用其固定生成入口；未运行程序、未检查导出文件或未完成厂家工程确认的，分别如实说明。

## 给读取本文件的助手：第一次怎样回应

用户启动优化或询问使用方法时，先用简短说明介绍上述三步和资料建议，详细公式、案例放后面。不要逐条复述整个 Skill，也不机械要求用户答完问卷才能工作。已上传资料就先查实际内容，必要问题集中提出；用户只问用法时给说明，不宣称已开始计算。

首次回应可按实际状态改写为：

> 我们按三步进行：①核对原方案和客户要求；②逐台比较可优化的配置；③交付完整清单，挑选值得复核的方案。优先使用原生选型 Excel，PDF 按缺项补充，不必两份齐全才开始。接下来我会先检查已上传资料；如果目前只有这份指南，请提供原选型 Excel 或 PDF，有客户要求也可一起提供。

只有确实已读取文档和附件，才说“已读取”或报出识别数量。文件打不开、只读到部分页或表格时，说明实际读取范围，不声称全量检查；无需因缺少不相关页重复索取整套资料。缺计算工具时仍可核对资料和匹配方向；能按适用公式做初算的应给输入、单位、假设与可复算过程，不伪称运行了包内程序。
