# 独立初算与检查输入

先按[软件前离线预选](offline-prescreen.md)确定逐台方向、Cv/行程/执行机构潜力和需核验的项目；本文件维护公式及证据边界，不把本地检查器状态当作离线优化交付的总开关。

## 现有能力与边界

本项目从仓库根执行 `node tools/valvstream/pre-sizing-cli.mjs`；云端从 Skill 根执行 `node runtime/tools/valvstream/pre-sizing-cli.mjs`。都先读已有说明：项目 `docs/local-presizing.md`，云端 `runtime/docs/local-presizing.md`。不重写 Cv 引擎，不用另一套简化公式替换已有实现。

```
node <上述入口> inventory
node <上述入口> catalog <筛选条件.json>
node <上述入口> calculate <已核对输入.json> --out-dir <任务结果目录> --cache-dir <任务缓存目录>
```

调用时替换尖括号；以工具返回的来源、适用配置和缺口为准。云端包仅保留厂家曲线，不带客户历史案例及软件下拉框库；其候选不是软件已核实选项。28000 无逐点曲线等已知缺口沿原工具说明，不外推。

已有 Cv 公式来自固定的 Masoneilan Sizing Handbook（液体第5页、气体第13–14页）：

- 液体 `Cv = W / [27.3 × Fp × √(ρ × ΔP有效)]`；气体在分母加入膨胀因子 `Y`。W 为 kg/h，ρ 为 kg/m³，压差为 bar，涉及压力比与饱和压力时用绝压。
- 液体 `ΔP有效 = min(P1−P2, FL²(P1−FF×Pv))`，`FF = 0.96−0.28√(Pv/Pc)`；气体按比热比、xT 和实际压力比限制压差并计算 Y。执行细节以固定引擎为准，不猜混合物物性及系数。
- 开度：优先反查匹配内件/特性/等级/流向的厂家逐点曲线；条件估算按下节处理。不按“需求 Cv / 额定 Cv”当开度。软件中的 `% Travel` 是阀杆开度，`% Cv` 是需求Cv占额定Cv的比例，必须分别记录。即使特性名称为Linear，两者也不能互代；目录估算与当前软件结果不一致时保留差异，软件开度覆盖本次候选展示，不能默默改写旧证据。
- 流速：`v = (W/3600/ρ出口) / [π(d实际/1000)²/4]`，d 为 mm。气体须确认出口物性，不能直接使用标准体积或入口密度。按公称口径平方比例得到的估值仅供粗筛，不冒充实际内径计算。
- 几何对照：减Cv候选按适用厂家样本和配置参数逐档核对喉径，适用圆截面时算`A=πd²/4`、`面积减少比例=1−(d新/d原)²`。原尺寸由目录匹配而非实物确认时明确标注。圆截面积、多孔孔口总面积、液压力净受压面积分别命名；相同Cv不证明几何相同，Cv减小也不保证喉径减小。只有实际净受压面积有依据，才能进入下一项静力计算。
- 静力：`F液压力(N) = ΔP关闭(MPa) × A净受压(mm²)`。净面积必须来自适用结构；不默认等于阀座圆面积，不套给平衡结构。执行机构可用力须由最低供气、有效面积、弹簧范围/行程及厂家作用方式确定；完整需求还包括密封、填料/执行机构摩擦及规定余量，开启和关闭分别核对。减Cv时主动查明喉径是否改变，再计算有依据的净受压面积和带方向液压力变化；不把禁止比例缩总力理解成禁止估算变化部分。已有报告需求时，按[推力数据与执行机构预选](actuator-force-followup.md)做作用方向、弹簧及供气压差的有条件比较；其中87/88端点关系不是所有执行机构通用公式。

现有引擎 Fp=1，未实现完整异径管耦合、黏度修正、噪声预测、气蚀损伤和动作时间；缩径初算必须保留这些缺项。先算能可靠计算的部分，不能为等待完整模型而跳过全部初算；必要物性冲突时先解决，或只交付适用范围明确的边界估算。

## 缺系数、曲线或噪声时

先核对规格书原页、合并页及附件，区分没有提取、匹配错误和确实缺少。每个结果保留文件/页码、工况、单位、算法版本、假设及适用配置；同一行可以同时有独立需求Cv、估算开度和引用噪声，不能只用一个“已计算”标签覆盖全部字段。

- **气体xT**：表示阀门在规定参考条件下达到阻塞流的压差比特性，实际临界压差比还受比热比及安装条件影响。它与阀体、内件、开度和流向等有关，不是由流量或额定Cv单独决定。查适用厂家数据或已有软件记录；缺少时可用原报告的需求Cv、对应工况和同一公式反求等效xT，但须判断解是否可辨识、有无多解或对误差敏感。不能用额定Cv代替该工况需求Cv，也不能拟合原报告后再称独立验证。保存拟合残差、适用范围及有依据的敏感性区间；一个工况拟合值不得直接当作不同内件候选的实测系数。求不出可信值时保留范围或未知，不强行凑解。
- **Cv与开度曲线**：准确档位没有曲线时，可选择结构、内件、特性、流向等可比的最近Cv档位，将曲线逐点Cv除以该曲线额定Cv，再乘目标额定Cv，反查估算开度。记录借用档位、相似依据及误差风险；“最近Cv”不跨不适用系列、特性或特殊内件。禁止超出曲线覆盖区间外推。若兼容性不能成立，开度仍未知。此法属于估算，不证明目标档位可供货。
- **出口流速**：每个工况使用对应出口状态、密度及有效截面积，注明计算位置。只掌握公称口径或假定密度时可以粗算，但必须标明假设，不当实际流速验收；不同温压、相态不可直接套用入口或另一工况的密度。管道速度与阀出口速度不能混列。
- **噪声**：先提取原规格书噪声，保留“<”“≤”等关系和测量/预测位置，作为原配置基准。改变尺寸或内件后不能沿用为新方案噪声，也不凭出口速度平方比例推算分贝。新预测须有适用模型及其结构、流体、管道和声学输入；现有本地Cv引擎没有噪声模型。条件不足可先保留优化线索，补取结构参数或适用模型；不得自动转入软件；未知不等于不合格或合格。比较限值时保留严格/含等号关系，只有数值可确定时才给差值。

原配置与候选采用同一适用离线方法比较；已有软件结果只作可追溯基准。缺厂家系数/曲线时，先按上述方法做有条件估算或敏感性分析；缺关键工况、物性冲突或模型不适用时明确受影响项。缺资料不触发线上回算，也不得填造本地初算通过。

## 候选流速核对与完成检查

缩阀体、改变接口、减Cv或换内件，都按候选和有效流动工况记录管内平均速度、阀出口平均速度、内件喷口速度的“新计算／有依据沿用／粗估／缺项／不适用”及对应原因；三者不能互相代替。至少明确原与候选的质量流量、该位置密度和面积、速度、变化量及有来源的参考值/硬限值，单位与位置一一对应。不从公称DN、阀座圆面积或Cv值直接冒充实际出口流道、开度下有效喷口面积。

- 缩阀体但管道不变：同一工况、相同管径和管内状态下管内平均速度可以不变；候选阀出口面积可能减小，其流速必须另算。气体/蒸汽核对出口温压、密度和当地声速；马赫数是该位置速度除以当地声速，不能用管内马赫数代替阀出口校核。
- 同口径减Cv：只有同流量、同出口状态、同实际出口面积有证据时，才能沿用该位置的平均流速，并注明为何不变。内件通道、开度及射流可能变化，不能按Cv比例推算速度，也不能因阀体尺寸未变就不检查喷口。
- 闪蒸/两相：不能用入口液体密度当出口混合物密度；缺出口气相率、两相密度或适用模型时具体列缺口。喷口结构不明时先查厂家资料；确实缺孔数、孔径或开度下有效面积则标未算，不用阀座全开面积充数。
- 仅有公称尺寸或有依据的密度假设时，完成可做的粗估并注明限制；不能只写“待软件复核”，也不能把粗估称为实际流速验收。用户要求离线时继续用离线资料和模型处理，不自行切换软件。

`coverage.complete`仅核对工况名称和流量对应；不得以它、无容量排除项或报告生成成功来声明流速/全部计算完成。检查器的`velocityCoverage`仅汇总阀出口平均速度：calculated为已提交actual+verified参数算得的值，rough为粗估，omitted为无数值，unverified列粗估工况；complete只在源工况对应完整且全部流动工况有calculated值时为true。它不证明输入来源真实、模型适用、喷口已核算或符合限值；粗估数值缺有效假设时仍看missing。零流量不要求流动校核。批次交付另列每个位置的覆盖和待核情况，保留缺项方向但不标通过。验证脚本的测试通过与工程计算完成分开命名。

## 流速参考与推荐取舍

无项目或具体阀型明确硬限值时，采用下列数值作离线推荐的初筛参考，不称为统一强制规定。先区分出口相态、计算位置和资料适用范围；有适用硬限值则以它为准，保留原来的严格/含等号关系。

| 工况 | 初筛参考 | 来源与适用边界 |
| --- | --- | --- |
| 普通清洁液体，不气蚀、不闪蒸 | ≤10 m/s | [Valmet手册第65页](https://www.valmet.com/globalassets/sharepoint/imported/flowcontrol_manual.pdf#page=65)原文是球阀、截止型等所列阀型连续运行的入口建议；进出口实际面积相同且密度基本不变时，才据此参考出口速度。其他阀型/异径出口另查依据，不能冒充美索尼通用出口限值。 |
| 气体、干蒸汽 | ≤0.3 Mach，作保守初筛 | [美索尼噪声手册第7页](https://dam.bakerhughes.com/m/403871c7a460561b/original/Masoneilan-Noise-Control-Handbook-English.pdf#page=7)说明超过0.3 Mach进入较大的下游管道时有扩管噪声与振动风险，不是统一判废线。Mach=出口速度÷出口状态下声速，不能换成所有气体通用的固定m/s。 |
| 发生气蚀的非腐蚀性液体 | 上限约2～5 m/s，按阀型选取 | [SAMSON技术文章第12页](https://www.samsongroup.com/document/w01420en.pdf#page=12)为降低气蚀冲蚀的建议；不能一律取5 m/s，也不能继续套普通液体10 m/s。 |
| 闪蒸气液混合物 | <60 m/s，作参考 | 同一[SAMSON文章第12页](https://www.samsongroup.com/document/w01420en.pdf#page=12)的混合物平均阀出口速度建议；按出口混合状态计算，不套入口液体密度。它不是本项目或美索尼硬限值，也不普遍适用于所有多相流。 |

这些参考约束的是适用位置的平均流速，不代替喷口、冲蚀、振动或噪声检查。低于参考值也不单独证明工程合格；粗估或关键物性/面积缺项仍保留其原有状态。

允许略超参考值的候选进入主报告并作有条件推荐，不因跨过上述参考值就自动淘汰。逐工况写实际值、参考值、超出量及比例`(实际值/参考值−1)×100%`，结合缩径收益、原方案到候选的增速、运行频次、相态、材料以及可查的冲蚀/振动风险说明取舍。没有统一的“稍超”百分比，不自行建立5%或10%的自动放行线；明显超出或已有损伤风险证据时不能只写“稍超可接受”。必要时并列较保守的相邻口径。

报告区分“未超过初筛参考”“略超参考，有条件推荐”“需进一步核实”“超过明确硬限值”。建议例句：“出口流速10.4 m/s，较10 m/s初筛参考高0.4 m/s（4%）；结合本方案收益保留为有条件推荐，出口面积与冲蚀风险待核。”例句不表示4%自动可接受。只有假设值时注明条件估算；不得据此写实际验收通过。客户规定或厂家明确适用的硬限值不能因上述推荐原则放宽。

调用检查器时，`velocityLimitMps`同时给`velocityLimitType`（`reference`初筛参考／`hard`明确硬限值）及`velocityLimitSource`。硬限值超出且无覆盖本实际值的`velocityDeviationAcceptance:{source,limitMps}`时排除；参考值超出保留有条件判断；未分类超限暂不进主表，保留待核。气体Mach参考先用出口声速换算，不能把0.3填入m/s字段，也不能删除真实限值绕过检查。

## 候选噪声重算与完成检查

改变阀体/出口尺寸、Cv、内件或级数后，逐候选、逐有效流动工况核对并重算噪声，软件最终复核不替代可完成的预估。先查适用厂家方法/模型和已有精确配置软件记录，核对流体状态、候选结构系数、管道与声学输入；已有来源可取的参数继续提取。缺本地模型时继续查适用方法；仅在用户范围允许时调用软件，不能把工具缺功能当作本轮可以跳过的理由。

确实无法计算时，逐项记录已查来源、缺少的参数或不适用模型、影响哪个候选/工况及具体补算途径；标为“噪声重算未完成”。不得只填“待复核”，不得猜结构系数、按Cv/口径/流速比例换算分贝，亦不得把输入假设没有依据的算数结果称为噪声预估。原报告基准、候选预估、软件核验三列分别留存，注明模型/版本、输入、假设、预测位置、单位和限值关系；汇总展示关键结果与条件，计算过程按需展开。

验收分别统计候选工况总数、有新预测结果数、未完成数和超限数。容量或源工况名称覆盖齐全不等于噪声算完；`noiseCoverage`只检查提交的新噪声数值覆盖，不核实模型真实性，也不证明符合限值。当前资料支持的估算须先完成；剩余确切缺项保留为未完成工作，不用更新规则或报告排版替代补算。已知超限方案按交付规则移至备查，未知不冒充通过或失败。

## 离线噪声方法与适用性

优先查[Masoneilan官方噪声手册](https://dam.bakerhughes.com/m/403871c7a460561b/original/Masoneilan-Noise-Control-Handbook-English.pdf)。其中的机械功率、声效率或管内声压级不能直接当作管外dBA；必须继续计算频谱、管壁传递、距离和A计权。气体示例区间公式不代表全部流动区间，亦不能覆盖所有多孔、扩散器及多级组合。

该手册Rev.B（06/2021）第5页明确仅概述方法，以流动区间I为例；第8页说明专用降噪内件还需随开度/压力比变化的厂家修正，已用于ValvStream。这说明公开手册不是完整的型号参数库，不等于没有计算方法；缺项应具体到适用Fd、孔道结构或厂家修正曲线，不能凭通用公式补成已确认预测。

[Lo-dB扩散板规格书Rev.C（01/2025）](https://dam.bakerhughes.com/m/30c4cb6af2f54d10/original/Masoneilan-Lo-dB-Cartridges-Plates-Tech-Spec-English.pdf)第9页的额外6 dB限于下游板紧接阀出口或仅隔变径管的安装，不能解释为任意阀内每级降噪6 dB；第3页的一般应用条件为系统绝对压力比至少4:1，较低比值须另有适用依据。噪声手册第13页要求先用板入口压力重算阀门，并单算板噪声，再对各上游声源按下游限制装置数量衰减（每个6 dBA、最多12 dBA），最后对数合成；最末板自身噪声不扣6。初选可按板两端绝对压力比2:1，同时阀门至少分担总压差20%，但实际分压须用已选板CV核实。原配置已有降噪件的效果不能再次扣除，分压改变后须重算CV、开度及安装影响。

可复用[Fluids的IEC噪声实现与公开算例](https://fluids.readthedocs.io/fluids.control_valve.html#noise-generated-by-control-valves)，固定实际使用版本并先验证公开算例；这只是可选计算依赖，不表示本Skill分发包已包含完整噪声引擎。计算记录须含压力绝压转换、运行Cv/Kv、原/新额定Cv与开度、候选FL、Fd、管内径和壁厚、流体及管壁声学参数、安装修正、输出位置。不得把额定Cv直接当作运行Cv，也不得把旧FL直接当成候选FL。型号曲线上的FL按本候选开度插值；缺参数先查资料。

气体模型不能对所有结构沿用默认声效率系数。IEC60534-8-3:2010表4的典型An/Stp分别为：普通笼式−3.8/0.20，抛物线或V口阀芯−4.2/0.19，多孔顺流开−4.8/0.20、多孔顺流关−4.4/0.20；实际值仍应由厂家提供，专门控制孔径/孔间距降噪的内件另需实测声效率。Fd表和An/Stp必须对应同一结构、流向，不能混搭表行；对假设参数扫描所得区间仅称敏感性情景，不是实际预测范围。原表Valve Velocity等数值列可能与单位列交错，按表头逐工况提取，不能用全部字段通用的相邻列偏移；用软件流速/马赫数核对声速时注明这是原结果的内部一致性检查。

[Emerson公开Fd表](https://www.emerson.com/is/content/emerson/en/final-control/flow-controls/documents/cat12_s1.pdf#page=1)只给全尺寸内件的典型值，按相对流量系数和流向使用，不是其他厂家具体内件的实测值。只能在结构可比且假设明确时做条件估算；减小通道、多孔阀笼或抗汽蚀内件不能冒充普通抛物线阀芯，亦不得擅自把示例60/120孔当实物。多孔结构需有效孔数、孔径及相应模型，带扩散器需分段压力和声源组合依据。

[IEC 60534-8-4:2015公开预览第5页](https://assets.vde-verlag.de/iec-normen/preview-pdf/info_iec60534-8-4%7Bed3.0%7Db.pdf#page=5)明确排除闪蒸，试验验证主要为水、DN15–DN300及入口压力不超过15 bar；其他流体适用性未确认。烃类或超范围结果仅可作为模型诊断情景，不能借用±5 dBA精度承诺，不能据此判符合合同，也不能计入已完成的候选噪声数。P2≤Pv时不得夹紧压力比强行套普通液体公式。组分不明的C2/C3/混合液不得按名称猜纯物质声速。

尽可能用相同模型回算原配置，保留原Excel界限及原/新输入。若原表为“<70”等界限，差异只能给下界，不能当精确70相减；明显不能重现基准时先调查参数和适用性，不用调整系数拟合后称独立验证，也不凭候选/原模型差值宣称降噪收益。统计分别列有条件估算、模型诊断情景、无可用数值和已确认通过，诊断情景不得填作检查器的`prediction`。

## 候选检查器与输入

在本Skill根执行：

```
node scripts/check-candidate.mjs <候选.json>
node scripts/check-candidate.mjs scripts/fixtures/candidate.json
node --test scripts/check-candidate.test.mjs
```

第二条是包内可直接运行的[合成输入](../scripts/fixtures/candidate.json)，其数值、限值及证据名称只供测试，禁止当作客户数据或默认要求。检查器不代算Cv，不读取证据文件来核实真实性；应将实际计算结果及来源填入输入，保留原始输入与输出。它仅检查提交的声明和数值，不签发业务Gate，不批准页面动作，也不选择试选优先级。

| 字段 | 内容与约束 |
| --- | --- |
| direction | `body`缩阀体；`cv`阀体不变且额定Cv降低。 |
| pipeNominalMm | inlet、outlet两端管道公称口径，单位mm，必须有来源。等径阀体对两端分别检查半管径限制；异径阀门不送此简化检查器，应逐端评估。 |
| baseline / candidate | bodyNominalMm、ratedCv及完整非空packing对象。填料字段、类型和值须完全一致；“同原来”不能证明配置完整。其他固定配置也须按主流程核对，检查器未自动核对它们。 |
| evidence | 非空来源引用数组，指向本次输入、计算、曲线、假设等证据；仅路径存在不证明独立计算。 |
| calculationBasis | type为`independent`独立初算、`estimate`有条件估算、`software`软件结果或`reference`原报告引用，description说明具体来源/方法。estimate还须有非空assumptions数组。reference不能替代候选计算；混合依据按最弱计算依据申报，并在证据中逐字段说明。 |
| sourceCases | 采用来源中全部工况的name、massFlowKgH数组；名称唯一，流量已可靠换算到kg/h，包括零流量。未核实换算时不能伪造数值补齐。原单位和换算依据另保留。 |
| cases | 逐工况name与sourceCases对应，massFlowKgH相同；不能漏最小/正常/零流量点或混入不同工况。requiredCv是该工况需求值，不能用额定值代替。estimatedTravelPercent为适用曲线反查的百分比。停流点需求Cv为0，不要求开度。 |
| cases[].travelLimits | 可选客户明确硬限制，含minPercent与maxPercent。无要求时不填；接近全开提示不构成通用90%不合格线。检查器按优化候选需保留余量，达到或超过全开排除。 |
| cases[]流速字段 | outletDensityKgM3、outletDiameterMm、outletAreaBasis（`actual`实际流道／`nominal`公称口径）、outletDensityBasis（`verified`对应出口状态已核实／`assumed`假设）。仅actual+verified输出velocityMps；其他输出roughVelocityMps并要求velocityAssumptions说明假设，保留实际核验缺项。velocityLimitMps配velocityLimitType（reference/hard）及velocityLimitSource；按≤比较，来源严格<时另核边界。适用偏差接受给velocityDeviationAcceptance:{source,limitMps}，推荐取舍写decisionBasis。 |
| cases[]噪声字段 | noiseDbA、noiseBasis（`prediction`候选新预测／`original-report`原报告）、noiseRelation（`=`、`<`、`<=`、`>`、`>=`）。引用原值不会输出为新噪声。噪声未知填null；noiseLimitDbA有值时必须同时给noiseLimitRelation（`<`或`<=`），无客户限值填null。 |
| forceScreen | 可选shutoffMPa、netPressureAreaMm2、availableClosingN，均须有适用来源。仅比较关闭液压力下界；不足排除，足够仍不证明完整执行机构合格。 |

输出schemaVersion为2，状态保持原有四种：REJECTED、NEEDS_DATA、DEVIATION_REVIEW、READY_FOR_SOFTWARE_CHECK。分别表示存在排除理由、相关依据缺项、已有明确偏差、可进入软件检查准备。多个问题可以同时存在，应读全部问题列表；不能只按状态筛掉清单。新噪声未知会保留待算项，不凭空生成限值。范围偏差是否接受需有对应依据。

coverage.complete只证明所提交源清单和结果的名称、流量对应完整，不证明源清单真实完整，也不证明每个结果已经可靠算完。noiseAssessment按数值及上下界作判定；例如预测<85可以满足限值<85，预测<=85则不足以证明满足严格<85。界限不足时INDETERMINATE，不能用“85”当精确值算差。trialPriority固定NOT_ASSESSED，liveValidated与businessGatePass始终false；软件来源声明也不能改变这些标志。

旧格式仍可读取，但缺少sourceCases、计算依据或流速/噪声来源时保守提示缺项，不再默认为独立计算。升级调用方须从真实证据补充这些字段；历史任务脚本、冻结输入和结果不批量改写为新格式，更不能重标为已验证。需要重跑的任务另存新输入与版本。

## 数值可行与试选价值分开

检查器数值通过只说明没有触发它覆盖的排除项。仍须逐路线说明开度/余量改善、原噪声与流速水平、缩径增加的风险、实际可选内件和执行机构、可比价格。缩阀体风险升高而收益不明时可不继续，同口径减Cv仍可单独评估；同口径减Cv也不自动降噪或缩执行机构。最终清单保留全部阀门及适用路线判断，关键结果在前，计算依据及详细候选在后。

特殊配置降本按 [cost-reduction.md](cost-reduction.md) 另行评估；本检查器的direction仅限body/cv，其他方向返回不支持不代表该工程方案已被判定不可行。不能为让它通过而隐藏系列、流向、阀盖、连接或定制设计变化。


新总需求缺参时，默认先按推力参考2.3节给开启/关闭“比原需求多出的力”和百分比，并比较原尺寸在新行程下的保守方案；不默认假设新需求不增。用户先要会话解释时不修改交付表，撤回假设即停止采用。用户明确停止噪声计算时不继续重算或匹配软件，本次未复核不当作噪声合格；其他任务仍按适用计算规则执行。
