# 阀盖与填料温度表：EB优化内置资料

本表把21000、41005样本中与标准阀盖、加长阀盖（EB）和填料有关的温度数据直接收录，完整包和单文件聊天指南使用同一份正文。已于2026-11-14逐项对照PDF表格图像和脚注；无需为了下列已收录组合重新上传样本。

## 怎样用于取消EB

原方案满足温压、原材质/压力等级/工况不变时，沿用原承压结论。先匹配系列、原完整填料和本表适用配置，再比较原设计最低/最高温度：全部在对应**标准阀盖**区间内，可提出取消EB；超出则保留，未收录或不清楚则只标明具体缺项。客户明确要求EB时保留该要求。不重新计算原承压额定，不增加样本未要求的热分析。

温度采用样本标出的摄氏数值，不用重新换算的尾差改变边界。下表端点属于原表范围；同时保留华氏原值便于追溯。表列的是相应填料/阀盖组合的范围，不能拿来提高原阀门的设计温度或改变原填料。

## 41005：第24–25页填料与阀盖表

页面型号范围：41X15、41X25、41X35、41X45、41X55、41X95。页面另列高容量41XA5/41XB5/41XC5：6/8英寸限302℃，10–24英寸限232℃，不能用下表填料上限放宽这些结构的原限制。

下表“PTFE组合”按样本区分：Class 150–900为Carbon Core Braided PTFE（碳芯编织PTFE）；Class 1500–2500为PTFE/Carbon + Braided Graphite End Rings（PTFE/碳填料配编织石墨端环）。**带石墨端环的PTFE组合不等于整套柔性石墨填料，不能套用B41-04。**

保留的边界与脚注：

- 上述范围从第25页下半部分“Optional Configurations and Materials”的温度轴与填料单元格边界读取；B41-01并与第24页标准碳钢填料行交叉核对。第25页下半部分不是仅适用于上半部分不锈钢材料的独立整阀承压表。
- 第25页上半部分脚注2另给低温阀盖结构提示：-46～-100℃用低温加长阀盖，-101℃起用深冷阀盖；印刷文本末端写为“196℃”，缺负号。本表不静默改写该脚注，也不拿它覆盖下半部分填料组合的-73℃分界。低温结构范围与填料组合范围不能混作一个数值；它们均不支持在低于-29℃时套用本表标准阀盖。
- 第25页列有Low-E Packing配标准长度阀盖，但其应用细则指向独立样本Ref.32991。当前未收录该独立样本；不猜完整温度范围，也不把普通PTFE、石墨或21000的LE范围移用到41005 Low-E配置。
- NACE专用配置、API 6A及其他未列设计不自动借用本表；对应专用表未在此完整收录。这不影响已明确属于上述普通配置的判断。

## 使用示例（仅检查本表温度范围）

假设原配置匹配上述普通型号、完整填料保持，且无明确必须保留EB的要求：

| 原配置与设计温度 | 直接查哪行 | 温度判断 |
|---|---|---|
| 41005、柔性石墨、425℃ | B41-04：-29～566℃ | 标准阀盖范围覆盖，可列取消EB候选 |
| 21000、石墨、425℃ | B21-03：-29～427℃ | 标准阀盖范围覆盖，可列取消EB候选 |
| 21000、石墨、450℃ | B21-03 | 超出427℃；不能借41005的566℃证明可取消EB |
| 41005、上述PTFE组合、425℃ | B41-01、B41-03 | 超出标准阀盖343℃范围，落在高温EB组合范围，保留EB |
| 41005、柔性石墨、设计-55～100℃ | B41-04 | 最低温度低于-29℃，不能只看最高温度就取消EB |

交付时写明实际匹配行、样本版本/页码、设计温度范围、标准阀盖范围及判断；引用这些内置数据不冒称进行了新的厂家确认。仅有“Graphite”等缩略材料名时结合原完整配置识别，不能把PTFE的石墨端环误作柔性石墨填料。
