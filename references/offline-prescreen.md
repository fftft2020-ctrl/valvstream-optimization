# 软件前离线预选

开始优化预选时读取本文件。目标是在不操作选型软件时，先判断每台值得走哪条路线、优先比较哪些档位、可能获得什么收益。计算细节和系数缺项处理沿用 [calculation.md](calculation.md)，先按 [optimization-map.md](optimization-map.md) 的前三类通用方法筛查，再单独匹配第四类 [具体配置案例](cost-reduction.md)，保留命中情况和条件；不因未命中通用方法漏掉具体案例。不把工程方向、机构预选和最终供货认可混成一个状态。

## 1. 把输入和候选结构对应清楚

- 冻结原方案和全部有数值源工况；客户要求、原方案自身偏差、优化引入的变化分列。正常/最小栏无数值不补造工况；关闭压差和设计温度不由运行点代替。
- 先匹配系列、内件、特性、流向、等级、阀体/端口及材料。读取适用目录的候选范围；计算器摘要最多几条不等于目录只有几条。用 `capacity-directory` / `catalog` / `curve <ID>` 取所需记录，不加载全库或重复扫描PDF。
- 每档同时记录额定Cv、开度曲线、阀体/内件尺寸、额定机械行程及其来源。开度百分比与机械行程长度是不同量。不能用相同Cv数字连接不同配置，不能假设Cv越小、行程越短。
- 厂家档位与已有完整软件选项记录分开标注；后者有日期和精确配置也只证明当时可选。本地没有软件选项，不妨碍按厂家资料提出方向；不得伪称已确认当前可供货。分发包不含软件下拉框库。
- 仅接口保持不变而主体/内件结构改变时，单独标记结构变化，不能称为纯粹同阀体减Cv；仍核对半管径、连接和实际出口截面。

## 2. 先算容量、开度和方向是否稳定

复用已有引擎覆盖全部有数值源工况，按适用曲线反查候选开度，记录表外、特殊流态和修正缺项。若仅本地缺候选xT等系数，可按计算参考采用原报告需求Cv作条件估算或用有来源的系数范围作敏感性比较；不填写假系数，不宣称独立重算完成。

敏感性分析看“系数变化是否改变可用档位、开度余量或试选顺序”，不以拟合原软件小数为目标，不设通用±百分比。有依据的范围内始终有余量，可提高试选优先级；结论会翻转时指出决定性缺项，其他已支持方向仍交付。

有意义时列出 `额定Cv / 最大工况需求Cv − 1` 的容量余量；它不是剩余行程，也不自动等于可增加的实际流量。预计开度和实际流量余量按相应曲线、系数和模型说明。缩阀体还应比较流速/噪声风险；原噪声只能作基准，不能冒充新预测。

## 3. 联合预选行程与执行机构

原Cv不变时也可单独审查较小机构，不以先减少Cv为前提。用户承诺后补或已提供执行机构推力报告时，先查任务待办，并按[推力报告后续验证](actuator-force-followup.md)识别负荷/输出及包含项；未验证状态保留，不把报告值按比例当作所有新配置的需求。

**先查行程是否支持，再核对开启和关闭负荷。** 从适用厂家机构资料查允许行程、作用方式、弹簧选项、最低供气下的输出能力和连接适配。候选行程超出某机构范围时，不继续把该机构列为可缩小目标；行程缩短到较小机构支持范围时，列为值得检查的机会。

负荷预估使用有来源的关闭压差、完整填料/密封、失效动作及本轮适用的压差加成和安全系数，分别核对开启和关闭。原表压差、协议加成与力的安全系数分别记录，核对软件是否已包含，避免遗漏或重复叠加；用户仅为内部试算暂不采用某条款时注明范围，不推广到正式选型或其他项目。净受压面积须适用具体平衡/非平衡结构，不由Cv反推，不一律取阀座圆面积；可用力须考虑弹簧及全行程，不能只拿供气压力乘隔膜面积当完整校核。阀杆强度/屈曲、机构安装和要求的动作性能也须保留检查。

按证据明确写到哪一步：

| 已有依据 | 离线可交付的判断 |
| --- | --- |
| 只有候选行程与机构允许行程 | “具备缩短行程/采用较小机构的可能”，推力与具体型号待核 |
| 有适用净面积、负荷下界和机构输出上界，已不足 | 不能标为现有条件下通过；若存在有依据的缩小收益和明确待解决条件，可保留有条件建议，列明不足原因；不等于排除该阀门所有优化路线 |
| 只有部分负荷且看起来足够 | 仅通过局部初筛，不能称完整机构通过 |
| 完整负荷、弹簧/全行程能力、材料/连接/动作等依据齐全 | 给出带来源的机构预选结果及余量，最终软件或厂家核验仍单列 |

**气源符合性与缩小收益分列。** 最低保证供气是客户保证可用的下限，不是供气上限；软件所需供气须核对字段、单位、原始精度和实际警告，不把推荐设定压力或显示舍入值当最低需求。仅因原机构在最低气源下不通过，不能停止寻找更小Cv/内件可降低负荷的路线。

对有依据的较小机构候选，列出原/新Cv、各工况开度、行程、原/新机构及具体缩小量，同时列最低保证气压、所需气压和差额。所需气压超过保证值时仍列“有条件缩小建议”；不得擅自提高可用气源或消除失败警告，也不默认任何差额足够小可以忽略。供气满足只代表气源这一项满足；关闭力、弹簧、连接或附件另有失败/未知时仍保留。只有行程匹配的写“缩小线索”，只有Cv变小而机构不变的不计为缩机构收益。最终推荐需解决相关条件；候选检查器的REJECTED/NEEDS_DATA保持原意，不因展示保留机会而改成PASS。

保留的配置须对照原始要求，不能以曾保存的试选默认值当原要求。更正填料/密封/行程等后，使受影响的负荷和机构结果失效并重算，不继续引用旧结果。

## 4. 按收益与代价选少量候选

- 优先比较可能缩机构、缩短行程、减少特殊结构或改善必要控制性能的档位；容量足够且开度更接近全开，本身不是降本理由。
- 用户目标为缩小时，需要更大机构的档位不列为优化推荐，仅留历史试算或原方案问题；不以纠正原配置取代寻找缩小机会。机构没缩小、价格收益未知而余量明显减少时，可保留原方案或较大档作为主选。
- 从适用候选范围中挑有结构/行程/负荷差别的少量方案，通常1–3档。优先选能跨越机构行程/负荷限制、可能转入更小型号的档位，不只取最接近原Cv的一档；行程缩短但机构不变须如实写明。不是按Cv从小到大机械取前三，也不需要软件逐档穷举。
- 判断紧贴关键代价：所有工况开度、容量余量、若可算则最低可用供气减所需供气的差额、流速/噪声风险。没有依据不设通用开度阈值、气源差额或最低节省比例。
- 没有同供货范围价格时，只写可能节省的部件或费用方向，不给精确节省金额。原报价、某阶段部件价格、整机内部价格和正式供货报价分别说明。

## 5. 离线交付先完成，软件核验后置

每台至少给出：**建议路线/保留原方案；原配置→候选；源工况对应的预计开度；行程变化；机构缩小潜力及依据等级；收益与代价；下一步需验证的最少项目。** 每个字段分别标为原报告引用、厂家资料、独立初算、条件估算或已核验的历史软件结果；未知项注明影响，不能让未知项抹掉已有判断。

交接软件的目的应明确，例如“验证候选系数后容量是否仍足够”“验证较短行程下较小机构推力是否足够”，而不是重新无目标探索全部档位。真实操作仍按主Skill的授权与业务检查执行；当前软件出现不同可选档、行程或曲线时记录偏差并重评，不强行贴合离线答案。原密封/材料选项缺失时标“原配置无法复现”，查同尺寸/等级/材质/内件的实际组合或厂家特殊设计，不以相近材料替代，也不据此判无优化空间。已试失败只限定已试组合，不外推到全部档位。

## 当前工具能力与复用边界

现有 `pre-sizing-cli.mjs` / `pre-sizing.mjs` 提供需求Cv、厂家逐点开度反查、行程元数据和有依据的系数情景；**未集成完整机构负荷计算、机构自动排名、新噪声、实际出口速度或价格模型**。候选检查器的静力项仅比较关闭液压力下界；程序排序不是本文件的工程收益排序。行程与机构资料的联合判断由执行代理按本参考完成；有完整数据时可用可复算的算表，不能把本次规则更新描述为已实现新计算引擎。

项目可按需读取 `valvstream-selection` 的机构产品资料；独立分发包只有厂家阀门曲线，没有完整机构性能库。缺机构资料时交付方向和具体缺项，不为此停掉容量、开度和行程比较。

新软件记录可用于核对离线预测及积累精确配置证据，保留偏差原因；不能把事后知道的机构答案当作当时独立预测，或将单一“Cv→机构型号”关系固化成通用规则。
