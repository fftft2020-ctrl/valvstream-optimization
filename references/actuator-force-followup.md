# 推力数据、机构预选与后续验证

可用能力：**引用已核对的需求推力，结合适用厂家资料做机构端点初筛和供气估算。** 87型机构配SVI3单作用定位器的部分供气显示值已有真实资料回溯对照；这不等于独立重算了阀门负荷，也不证明其他机构、新内件或完整行程已验证。当前程序没有新增完整推力引擎；本文件指导有来源、可复算的分析。

## 1. 先查已有数据，不固定等PDF

先查任务记录、原生Excel和已有报告。原生配置表若提供`Required Thrust Open`、`Required Thrust Close`及`Thrust UOM`，核对报价版本、Item+Tag、阀门配置、单位和数量后即可作为需求来源，不为这两个数重复导出推力PDF。保存源文件哈希、工作表/字段及配置对应关系。原生xlsx若错误声明范围为A1:A1，须检查实际工作表内容；使用openpyxl只读模式时可`reset_dimensions()`后重新读取，不能把错误范围当成只有一个单元格，也不修改原件。

开始资料核对时，按[使用说明的安全系数核对](getting-started.md#开始时先核对执行机构安全系数)取得本轮适用值、来源及位号范围；已有且适用则告知后继续，缺失才询问。系数未明确，不以原始需求与名义输出的比较宣布较小机构足够。

区分阀门所需负荷、机构必须提供的输出和实际可用输出。表头类似不证明含义相同：需求字段、备选列表的力及阀杆允许力不能混用；备选列表两列也未必都是最大能力。用同配置原报告、实际字段和厂家定义交叉核对，不单凭数值恰好等于面积乘压力作结论。

记录力的开/关方向、作用位置、行程及是否包含密封、填料摩擦、安全系数和原机构损失。已计入的项目不重复添加；若需求包含原机构特有弹簧/损失，先分离后才能用于其他机构。只有最大需求值而无沿行程数据时保留该限制。

安全系数必须单列为验算条件：给出原始需求、系数是否已计入、计入后的门槛、候选输出及差额。原需求已含系数时不得重复乘；尚未确认包含关系时不能把“输出大于原始需求”写成满足原安全系数。可在已授权试算中做单变量诊断，比较系数变化前后的需求字段和候选列表，随后恢复原系数；降低系数只作诊断，不作未经批准的优化方案。关闭方向弹簧力差额很小也须如实判失败，不能用提高气源消除。

确实缺数据才列具体缺项并提醒一次，继续不依赖缺项的工作。数据已取得则更新任务状态，不保留过时的“等推力页”。具体位号、客户限值、真实算表和试算豁免留在任务记录，不放入公共Skill。

## 2. 计算到哪一步，要分别说明

| 依据 | 可交付结论 | 仍不能声称 |
| --- | --- | --- |
| 原报告需求＋名义面积/弹簧端点 | 同阀门配置下的机构初筛、明确假设的供气估算及不足量 | 已独立预测阀门负荷，或完整机构合格 |
| 同口径、同配置历史软件结果＋厂家定义 | 原配置的回溯对照、解释有依据的差额 | 新候选盲测通过，或软件内部算法已查明 |
| 沿行程负荷和机构能力、安装/附件/阀杆等齐全 | 带来源和余量的机构预选，提交适用软件或厂家核验 | 未核验的新配置已获供货批准 |
| 改Cv、填料、内件或流向 | 有依据的变化部分计算、边界或缺项 | 沿用旧总推力，按Cv或阀座面积比例缩放总需求 |

只引用原需求时明确写“原报告需求＋候选机构能力比较”。保留原Cv、完整填料、内件、流向、关闭压差、失效动作及附件，先比较较小机构；客户要求与原配置冲突另列，当前结果不能代替修正配置后的结果。

## 2.1 交付必须可核对的机构结果

对每个涉及缩机构的候选，先完成以下记录，再安排试选优先级。已有需求及适用厂家能力时，不能仅写“待软件复核”“具体型号待定”或只报行程；安全系数包含关系不明时，仍应计算两种边界，不以它为由跳过比较。

- **原需求**：开/关方向、单位、来源行/页、原配置及安全系数。直行程用推力，旋转阀用力矩，不混用。
- **机构能力**：原机构作参照，较小候选列型号、可支持的候选行程、最低保证供气下开/关输出、面积/弹簧/作用方式依据及未扣除损失。缩短后的行程进入比较，不能只按原行程排除新候选。两侧面积未知对应时可取较小侧作保守比较，并同时核对较大侧上界；不能仅因保守下界不足宣布所有方向都失败。
- **两组差额**：输出−原始需求；原需求未含系数时，输出−适用系数后的需求。包含关系已核实则采用对应分支，另一分支仅作诊断。负差额必须显示数值和限制条件，正差额不能直接称整机合格。
- **原负荷与新负荷分开**：原配置不变才可直接按原需求筛机构。改Cv/喉径/平衡结构后，旧负荷下失败只排除直接替换，不排除新负荷下降后缩机构的路线；新负荷未算时明确标未算，不继承旧负荷的失败结论或通过结论。
- **可见取舍**：主表只保留影响决定的结论与关键余量/不足量；“查看依据与计算”须含本方案的真实算表。失败候选不作推荐卡片，但须有每台可打开的计算备查，不能因没有成功候选而不生成计算入口。报告与Excel的型号、数值、取舍须一致。

只有行程线索、没有机构能力对照和负荷变化判断时，不得以“已证缩机构收益”为由标优先。可有其他独立收益支持优先，但须说明该收益的证据，不能以容量算通替代。

## 2.2 减Cv后的主动计算链

逐候选检查 **Cv→实际喉径→净受压面积→液压力分量→新总需求→较小机构余量**，不得止步于“不能按Cv比例缩总力”。

1. 查厂家对应结构和行程的原/候选喉径。喉径相同就明确写“本档无喉径缩小的降力依据”；不因Cv小就编造孔径变化。喉径变小则量化圆面积变化并继续查受压结构，不能只列面积百分比后结束。
2. 以具体阀座、阀杆、平衡密封/活塞、先导结构及流向核对净受压面积。圆喉径不是自动成立的净面积；先导阀还要区分先导开启、压力平衡建立与主阀芯动作阶段。资料查找结果必须落到具体来源和缺少的尺寸/压力，不用笼统“缺厂家资料”代替。
3. 对每个方向和控制位置，用带方向的液压力变化：`ΔF液 = ΔP × (A净新 − A净旧)`。MPa×mm²得到N；净面积以阻碍该动作取正、帮助该动作取负。阻力分量下降可减需求；助力分量下降可能增加该方向外部需求，不能默认开关两方向同时减力。压差随结构/位置变化时分别计算新旧压力×面积，不强行共用压差。
4. 若原总需求包含项和系数位置已核实，且其余项保持有据不变，可用 `F新 = F旧 + ΔF液 + ΔF密封 + ΔF填料/摩擦 + 其他已识别变化`，按原来源的系数施加位置处理；不把总需求乘Cv或面积比。其余项未知时先交付已算分量、可成立的上下界或反算门槛，不把未算项当0；也不把反算“至少需降低多少”冒充已预测的降低量。
5. 用新需求重新比较较小机构的开启/关闭能力及供气。找不到确切净面积时，保留已证的喉径/行程变化和原需求比较，列明确的补参项；不得宣称新结构无法缩机构。新结构失败须有该新结构的需求依据。

**可执行检查：** 有运行能力时，交付前逐候选调用 `reviewActuator`；`check-candidate.mjs` 会输出同名 `actuatorReview`。完整输入示例和错误反例见 `scripts/actuator-review.test.mjs`，示例全为合成数据，不套用其数值。`baselineDemand`/`candidateDemand` 用N，含安全系数值、`included/excluded/unknown`包含关系及来源；`capacities`含型号、开关输出N、输出依据与来源，`supplyMPa`必须等于本轮`minimumSupplyMPa`表压。`loadChanged`明确配置是否改变。改变时`geometry`必须给两档喉径mm及来源；`hydraulic`仅接收有来源和结构说明的`verified-net`带符号净面积mm²及适用压差MPa。缺面积时用`missingNetAreaEvidence`逐项说明已查来源与实际缺项。

检查结果分别记录：`comparisonComplete`（原需求对照是否齐）、`geometryChecked`（喉径检查）、`hydraulicChangeN`（有据液压力分量）、`newLoadComplete`（新总需求有无来源）；任何一项缺失都不能被容量的`READY_FOR_SOFTWARE_CHECK`覆盖。函数会保留不足档位，且不会把旧需求不足自动判为新候选失败。未能运行时按相同字段人工核对并明确未运行，不能声称自动检查通过。它只验证声明及有限计算，不证明来源真实性、完整机械校核或厂家认可。

## 3. 区分机构两种作用方向

先核对具体机构与行程匹配，再分别检查气动方向和弹簧返回方向。以适用的87/88直行程机构为例：87气压关阀、弹簧开阀；88气压开阀、弹簧关阀。整机故障位置还取决于保位阀等附件，不能只用机构型号推定整机失气动作。

下面是**忽略未量化内部损失的理想端点关系**，不是完整能力曲线。使用条件：厂家资料支持对应行程的名义面积及弹簧端点，需求在对应方向/位置有意义，采用表压，排气背压可忽略；条件未证实则标条件估算或待补，不能默认已满足。A为有效面积in²，F为力lbf（磅力），S_min/S_max为弹簧范围端点psi，ΔP_pos为适用定位器要求的供气压差psi：

| 机构 | 弹簧返回方向理想可用力 | 气动方向端点供气估算 |
| --- | --- | --- |
| 87气压关阀 | 开启力约A×S_min，对比F_open | P_supply约S_max＋F_close/A＋ΔP_pos |
| 88气压开阀 | 关闭力约A×S_min，对比F_close | P_supply约S_max＋F_open/A＋ΔP_pos |

最大需求与最不利弹簧端点未必发生在同一位置，组合它们仅为保守初筛；失败不能泛化为所有配置不可行。已有正背压、残压或内部摩擦时，按方向计入其抵抗力；未知时理想能力只是上界，不把未知损失默认为已核实的零。需求中已经包含的摩擦/余量不要再减一次。名义能力足够仍需全行程、行程公差、阀杆强度/屈曲、连接和动作时间核验。该关系不能直接套到活塞、双作用、旋转或特殊平衡机构。

供气与弹簧的作用不能互换：88的弹簧关阀力不足时，提高气源不增加其失气关阀能力。可反算`F_close/A`作为较小机构所需初始弹簧当量门槛，但它不是现成弹簧型号或预紧设定。加强弹簧/预紧必须另核对最高弹簧力、开启供气、实际可用行程、阀杆和厂家允许范围；不得凭端点平衡宣布可制造或可供货。目录中的长行程特殊弹簧范围不能直接移植到较小机构；当前表最小尺寸也不代表所有产品均无更小型号，其他规格缺数据时保留缺项方向。

## 4. 定位器压差与软件显示精度

[Baker Hughes SVI3手册](https://dam.bakerhughes.com/m/4ea9dc67afa1e36d/original/BHMN-SVI3-IOM-34587B-0421-English.pdf)（正文Rev.H/2026，第19页、2.3.3.3）给出单作用气动继动器的供气须至少高于机构所需压力5 psi；第34页、3.5另给出高于最大弹簧范围5～10 psi的安装说明。前者是适用设备的工作压差，不是通用阀门摩擦修正或安全系数。使用时核对实际定位器型号、单/双作用、版本和气路；其他定位器不得默认同为5 psi，带增压器或特殊回路还须核对实际要求。

已核对的部分87型配SVI3记录中，“弹簧上限＋关闭需求/面积＋5 psi”再向上取整与软件显示一致。仅限回溯解释显示值：保留未舍入值、报告显示值及残差，不将向上取整固化成所有软件/机构的内部算法，也不把显示设定值自动当作真正最低需求。88型或52型须按各自作用方式及适用数据单独核验。不能把5 psi再次加到已经包含该压差的软件供气结果上。

纯合成算例（非客户数据）：A=100 in²、87型11–23 psi弹簧、F_close=2600 lbf，则气动端理想需求49 psig；若已确认适用SVI3单作用5 psi压差，供气初算54 psig。弹簧开启力仍须另与F_open比较，54 psig本身不证明机构合格。

比较客户最低保证供气、机构/附件允许上限和所需供气三个不同量。气源范围的上限不能代替最低保证值；恰在显示舍入边界时核对原始精度，不能用取整制造通过。有依据但超保证值的候选仅在备查保留为受条件限制的缩小方向，列原始估算、显示值、差额和未通过项，不进入主报告的候选清单，按[offline-prescreen.md](offline-prescreen.md)处理。

## 5. 验证、续做和关闭待办

任务分别记录：原需求已取得／字段包含项已核实／原配置回溯已完成／新候选软件或厂家已验证；每项有自己的依据，不能用一个“已跑通”覆盖全部阶段。批次逐台继续，某台缺项不阻塞其他已有依据的计算。

原配置对照先解释重要差额，再列少量有依据的小机构候选及剩余核验事项。只达到端点初筛就注明范围；完整机构验证还须对应的全行程能力、客户要求、附件/安装/阀杆及适用工程核验。本Skill不进入真实页面；正式软件选型属于另行明确提出的任务。

改Cv或结构时按2.2主动查找并计算有据变化分量；不得整体按Cv、孔径面积或旧机构大小缩放完整需求，也不得借该限制停止已能完成的分量计算。客户填料与当前配置不同，修正后使受影响旧结果失效，不能继续引用原通过结果。

经验证的通用方法写回本参考；真实案例、来源哈希、误差及仍缺项写回任务记录。分发范围和版本同步按[sync.md](sync.md)，提交/推送依当时用户授权处理；已有原需求或部分供气回溯不等于完整推力引擎已实现。
