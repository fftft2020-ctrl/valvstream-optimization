# 第4类：具体配置优化案例——遇到以下情况，可尝试优化

## 来源与使用方法

来源是用户于2026-11-06提供的两张《MN-Cut Cost Check List - Dec.2025.xlsx》屏幕照片，第一张覆盖1–26行，第二张覆盖23–38行。共38个原编号，重叠行不重复计数；同样原配置的不同图纸方案分别保留。这是用户提供的工程经验线索，未经逐项厂家资料/图纸独立验证，不代表现行全系列产品资格或可供货目录。原照片及文件指纹保存在任务资料，分发包仅含本整理。

按以下方式使用：

1. 本表作为[优化目录](optimization-map.md)中独立的第4类，38条全部集中维护。逐台匹配以下具体情况，即可形成有条件的尝试方案；不要求先命中前三类通用方法。可以提炼“保持接口、缩小主体”等通用方法用于其他规格；不能把原实例尺寸、压力等级、曲线或图纸当作其他规格已经可用的证明。
2. 对命中条目保存原编号、触发条件、原配置→候选、明确改变的字段和仍须保留的要求。交付先显示这几个具体字段，不只显示“换系列/优化试验/更换来源”等分类名称。补齐表中条件，以及客户工况、介质相容性、温压等级、泄漏、连接和执行机构负荷。原表没有写条件不代表没有条件。
3. 清楚区分“读懂照片”“工况适用”“厂家已确认”“软件可算”“客户符合”和“报价更低”。表内温度、压差、Cv及图号是该条线索的条件/定位信息，不推广为通用限值，也不等于厂家批准。
4. 本轮以离线方法比较原配置和候选；需要软件或厂家应用工程（原表BH AE）核验的具体问题列入交接事项，不自动转入线上选型。定制阀体/内件缺设计依据时不能选择近似型号冒充验证。原表注明case by case、AE检查、定制或设计引用的，保留对应工程确认要求；普通读取和离线筛查不因此暂停。
5. 比较含附加件、管道修改、安装、试验及交期的完整方案价格。单件更便宜不保证总方案更低。收益尚无依据时先称方向，不宣称节省。

**范围示例：** 第20条只指21009由原表来源改DVI，不推广为所有产品更换工厂；第24条只指已明确不需要深冷测试的Cryo-Class V配置改普通Class V，不推广为寻找可取消的试验。完整供货费用比较是第5点的评价原则，不另列为照片措施。第30/31条不清楚的字段保持待核，不以笼统方向冒充完整候选。

K为照片中的系列简写，不能据此补齐具体型号。CL IV/CL V是此表的关闭泄漏等级；CL150/300/600/2500是压力等级，两者不可混淆。RF为突面法兰；BWE为对焊端；FTC/FTO是流向关/流向开；HW为手轮。DJL/DVI/CONDE等来源缩写及AE/SAE WF引用按原文保留，照片不清的字符不展开猜工厂身份。三段尺寸先按原文保存，进出口/阀体或内件的对应须用图纸确认。

## 第1条的厂家口径与泄漏边界

本节为厂家资料核验后的补充，优先于照片中的简略替换线索。来源：[Baker Hughes 41005技术规格，Rev. R / 06-2025，第5页](https://dam.bakerhughes.com/asset/8dbd2b45-cc01-4042-981f-9dfe6f62153f/Masoneilan-41005-Globe-Valve-Tech-Spec-English.pdf#page=5)，2026-11-07核验；原PDF SHA-256 `36e3d829f6efa5914b37ddcf200fe29b00b5bea70d4a4236cbdb6e5c2dbac080`。项目产品知识owner为 `valvstream-selection/references/product-catalog.md` 的1.1a；此处保留独立云端分发所需的筛查摘要，不分发厂家PDF或客户案例。

- 41905石墨密封：2–4in为III级，6–18in为IV级（均-196～454℃）；20/24in为IV级（-46～343℃）。温度还须满足材料限制。
- 41915/41925标准内件允许流开FTO或流关FTC，但没有“2–4in改流向即可达到IV”的厂家依据。软件仅提供III时先核对口径和精确结构，不能先归因于流向；其他419内件另查对应流向。
- 2–4in且要求IV：标准419替换不通过；仅保留厂家特殊设计确认方向，不降低泄漏要求、不为取得IV自动放大阀体。较大口径列IV不等于整套选型通过；仍核对温压、材料、关闭压差、执行机构和实际配置。
- 缩口/异径结构按厂家具体设计判断适用尺寸，不能按较大的接口套IV；未列尺寸不插值。修改流向若获授权试选，须核对完整配置及执行机构，实际结果如实记录，软件选项不替代特殊设计批准。

## 与通用方法及计算检查的衔接

- 缩阀体、同口径减Cv仍使用原计算和候选检查；其他方向不伪装成body/cv输入。现有检查器不核验换系列、定制孔板、改变流向、连接、特殊压力等级、试验或制造来源。
- 配置替换记录“原条目、命中证据、改变字段、初算/软件能覆盖的项目、厂家需要核对的项目、客户要求、实际价格”。不因现有程序不支持就排除工程方向，也不把普通Cv计算通过当作特殊设计批准。
- 原填料配置保留。本表第16条涉及阀盖，不构成改填料授权。其他材料、连接、密封、压力等级及附件变化只按对应条目的明确方向评估，不能顺带降低客户要求。必要试验不因降本删除。
- 半管径规则仍有效。扩大接口、异径阀体和三段尺寸须按图纸识别各端与主体，逐端及主体核对适用规则；不能以端口大掩盖不满足约束的主体尺寸，也不以“公称口径×面积比例”代替实际流道计算。
- 每台报告保留原方案和全部适用方向，先给最有依据的行动及其收益/代价；原表行号和详细图纸引用后置。没有命中或仍不清楚的条目不影响其他有依据的路线继续。
